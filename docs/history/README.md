# 과거 실험과 연구 이력

현재 제출 연구는 [공개 실행의 행동 단위 벤치마크](../../README.md)입니다. 아래 자료는 이전 연구 과정의 보존 기록이며 현재 15개 행동 비교와 합산하지 않습니다. 원점수, 원시 응답과 실행 코드의 경로를 그대로 유지했습니다.

| 자료 | 위치 | 역할 |
|---|---|---|
| 이전 합성 입력과 평가 | [data/expanded_frozen.zip](../../data/expanded_frozen.zip), [results](../../results/) | 원점수와 사후 민감도 보존 |
| 합성 진단 코드 | [action](../../action/), [scripts](../../scripts/) | 작성, 저장 예측 재채점과 당시 실행 도구 |
| 초기 전달 경로 복원 | [provenance](../../provenance/), [결과](../../results/provenance_components.csv) | 현재 핵심 행동 관계 평가와 다른 출력 범위 |
| 당시 실행 안내 | [프로토콜](../action_protocol.md), [새 실행 안내](../new_run.md), [검증](../verification.md) | 과거 자료의 재현 |
| 이전 저장소 소개 | [당시 README](README_before_current_focus.md) | 결과와 설명의 변경 전 기록 |

커밋은 실제 저장소 변경 시점과 변경 내용을 기록합니다. 실험 발생 시점과 제출 저장소 정리 시점은 서로 다를 수 있으며, 실험의 출처와 원래 파일 대응은 [source_map.json](../../source_map.json)에 있습니다.
