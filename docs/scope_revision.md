# 최종 채점 범위 보정

| 위치 | 변경 | 이유 |
|---|---|---|
| 배경 | 곡 목록, 토큰 사례 중심으로 한 쪽 압축, 팬 풍량 삭제 | 실제 평가 사례에 빠르게 도달 |
| 결과 | 보정 전체 진단 14/15, 15/15, 14/15로 통일 | 공개 질문에 맞춘 재채점 반영 |
| 판정 차이 | 원래 Agent 지시와 진단기 판단을 분리 | 재생 이력 사례의 판단 주체 구분 |
| 채점 보정 | 두 요소 제거, 남은 요소 재검토, 원점수 부록 보존 | 사후 분석의 근거와 영향 추적 |
| 설계 선택 | 반복을 줄이고 4.5절에 근거 집중 | 결과와 선택의 연결 |

검증: 경계와 복원 테스트 5개, 보정 테스트 2개 통과. 원점수 재현, 원본 hash 불변, 변화한 6개 행과 나머지 지표 불변 확인. 새 추론 없음. 단일 사람 판정의 세 불일치는 미조정 상태로 유지.
