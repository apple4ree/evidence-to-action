# 실제 공개 실행 기록 비교 결과

**실제 원본 14개에서 추출한 15개 행동을 세 방법으로 비교했다. 기존 합성 72개와 별도 실험이다.**

## 무엇을 수집했는가
새 원본은 MAST 10개, Who&When 13개, AgentHallu 8개, 총 31개이며 기존 AgentHallu 5개도 재검토했다. 원문에서 18개 입력을 추출하고 15개를 핵심 관계 진단, 1개를 출처 보존 전용, 2개를 판정 보류로 나눴다. 평가할 원문을 새로 생성하거나 변형하지 않았다.

원본 URL, revision, hash, 줄번호 또는 JSON pointer를 보존하고 대상 행동 이전만 추출했다. 전체 실패 라벨과 대상 뒤의 결과는 입력에서 제외했다. 정답은 새 예측 전에 별도 문맥 LLM 검토로 고정했다. 이번 선정은 내용 탐색을 통한 표본이며 오류 발생률이나 독립 일반화 성능을 추정하는 표본이 아니다.

## 비교 결과
| 방법 | 판정 | 전체 진단 | 오류 재현율 | 정상 오탐 | 판단 불가 | 평균 활성 시간 | 출력 토큰 |
|---|---|---|---|---|---|---|---|
| 직접 진단 | 14/15 | 12/15 | 7/7 | 0/5 | 2/3 | 23.0초 | 10,845 |
| 재검토 | 15/15 | 13/15 | 7/7 | 0/5 | 3/3 | 45.3초 | 22,036 |
| 단계 분해 | 14/15 | 12/15 | 6/7 | 0/5 | 3/3 | 46.2초 | 21,623 |

판정은 지정한 핵심 관계에 대한 Supported, Unsupported, Indeterminate다. 전체 진단은 고정 의미 요소, 근거의 정확성과 판정을 함께 맞힌 경우다. 의미 채점은 방법 이름을 가린 별도 문맥 LLM 검수이며 사람 검증은 0건이다.

**채점 범위 문제:** AHN08은 저장 위치를 질문했으나 정답은 단어 수 9의 출처까지 요구했다. AHN09는 파일 내용 보존이 중심인데 정답은 검색된 파일과 디렉터리 연결도 요구했다. 세 방법 모두 추가 설명을 누락해 두 사례에서 공통 감점됐다. 원점수를 유지하고 이 부분은 질문과 정답 범위의 정합성 문제로 분리한다.

## 두 방향의 실패 분석
- **MAST-R06:** 과거 재생 이력이 없고 현재 큐만 보인다. 직접 진단은 현재 곡 뒤라는 사실을 과거에 재생된 적 없다는 근거처럼 판단해 Unsupported를 냈다. 재검토와 단계 분해는 순환 재생 가능성과 이력 결손을 지적해 Indeterminate로 판정했다.
- **MAST-R03:** page 0에서 반환한 다섯 곡만 확인하고 조건을 만족하는 곡이 전혀 없다고 결론 내렸다. 직접 진단과 재검토는 관측 범위의 확대를 Unsupported로 판정했다. 단계 분해는 전체 범위 조건을 추출했지만 관계 검사에서 unresolved를 선택해 Indeterminate가 됐다. 코드 합성은 반환 관계대로 동작했다.
- 두 방법의 판정 쌍별 비교에서 직접 진단만 맞힌 사례와 단계 분해만 맞힌 사례는 각각 1개다. 재검토는 직접 진단의 오류 1개를 수정했고 악화된 판정은 없다.
- 게시 상태, placeholder 주소, 파일 내용과 계정 귀속 등 나머지 판정은 세 방법이 일치했다. 같은 판정이라도 필수 설명 누락은 전체 진단에서 별도 감점했다.

## 검증과 실행 조건
60개 완료 native 세션, 45개 최종 진단을 보존했다. 입력을 읽기 전 무응답이었던 1개를 중단한 뒤 1회 재시도했으며, 답이 틀렸다는 이유로 반복한 실행은 없다. 모든 완료 세션에서 준비한 전체 요청 텍스트가 실제 도구 반환에 있는지 확인했고 원문 참조 검사도 통과했다. 최초 spawn 메시지 본문은 암호화되어 정확 일치를 확인하지 못했으며, 이 점은 본문 입력 전달 검사와 별개로 기록했다.

실제 관측 alias는 gpt-6-astra, effort는 medium이다. immutable 모델 버전과 금액은 미확인이다. 시간은 native 활성 세션 시간, 토큰은 시스템 문맥과 내부 도구 왕복을 포함한다. 재검토 비용은 재사용한 직접 진단을 포함하므로 방법별 비용을 합해 고유 실행 비용으로 쓰지 않는다.

통계 단위는 14개 원본 그룹이다. group-macro 점수와 2,000회 그룹 재표집 구간, 출처별 분모, 모든 사례 결과는 results/breakdowns.json과 summary.json에 있다. 재검토의 관측 만점 구간이 100%로 퇴화하는 것은 작은 관측 표본의 재표집 결과다.

## 현재 선택과 남은 검증
직접 진단을 기본 구현으로 유지한다. 재검토가 고친 기록 결손 경계는 사람 검토와 후속 자료에서 다시 확인할 대상이다. 단계 분해는 요구사항 추출과 관계 판단의 실패를 나누어 조사하는 비교 방법으로 유지한다. 사람 주석, 개발자 조사 효용, 운영 오류 발생률은 아직 측정하지 않았다.

## 파일
- input_recipes.json: 원본과 정확한 입력 복원 규칙
- gold/, scoring_spec.md, freeze_manifest.json: 고정 정답, 채점 규격, 평가 전 hash
- responses/, predictions/, semantic_ratings.json: 원시 응답, 합성 출력, 의미 채점
- results/: 전체 및 출처별, 원본별 결과
- review/: 정답을 숨긴 사람 검토 페이지 생성 코드
